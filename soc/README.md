# SOC — Security Operations Center

## Overview

This folder contains my TryHackMe learning and practical exercises related to Security Operations Center (SOC) operations.

The rooms focus on security monitoring, alert triage, defensive security, and the daily responsibilities of a security analyst.

## TryHackMe Rooms

* SOC Fundamentals
* SOC L1 Alert Triage
* Junior Security Analyst Intro
* Defensive Security Intro

* Threat identification

## SOC Investigation Workflow

```text
Alert
  ↓
Triage
  ↓
Collect Evidence
  ↓
Investigate
  ↓
Identify Threat
  ↓
Determine Severity
  ↓
Respond or Escalate
  ↓
Document Findings
```
