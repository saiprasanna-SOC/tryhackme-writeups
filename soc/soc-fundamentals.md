# SOC Fundamentals

## Overview

This TryHackMe room introduced the fundamentals of a Security Operations Center (SOC) and the role of security teams in monitoring and protecting an organization.

## Key Topics

* Security Operations Center
* SOC team responsibilities
* Security monitoring
* Security alerts
* Incident investigation
* Threat detection
* Defensive security
* Security operations workflow

## What I Learned

I learned how SOC teams monitor security events, investigate suspicious activity, respond to security alerts, and work together to protect organizational systems.

I also learned about the different responsibilities within a SOC and how security monitoring supports incident detection and response.

## SOC Workflow

```text
Monitor
  ↓
Detect
  ↓
Triage
  ↓
Investigate
  ↓
Respond
  ↓
Document
```
